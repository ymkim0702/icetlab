# ICE-T Lab | Young-Min Kim

2026-10-29 현재 ChatGPT Sites 공개 버전의 GitHub Pages 이전용 파일입니다.
디자인, 이미지, 논문 목록/IF, 모바일 메뉴와 최신 모집 문구를 포함합니다.
빌드나 프로그램 설치 없이 사용할 수 있습니다.

## 처음 올리는 방법 (GitHub 영문 메뉴)

1. ZIP을 PC에서 압축 해제합니다.
2. GitHub의 새 저장소를 엽니다. 예: ymkim0702/icetlab.
3. 빈 저장소라면 `uploading an existing file`, 파일이 이미 있다면 `Add file` → `Upload files`를 누릅니다.
4. 압축을 푼 폴더 안의 `index.html`, `assets` 폴더, `.nojekyll`, `README.md`를 업로드 영역에 끌어 놓습니다.
   - ZIP 파일 자체를 올리지 마세요.
   - 바깥 폴더를 통째로 올리지 말고, 그 안의 파일과 assets 폴더를 올리세요.
   - 저장소 첫 화면에 index.html과 assets 폴더가 바로 보여야 합니다.
5. `Commit changes`를 눌러 main 브랜치에 저장합니다.
6. `Settings` → 왼쪽 `Pages`로 이동합니다.
7. `Build and deployment`에서 `Source`를 `Deploy from a branch`로 선택합니다.
8. `Branch`를 `main`, 폴더를 `/(root)`로 지정하고 `Save`를 누릅니다.
9. 배포가 끝나면 Pages 화면에 표시되는 홈페이지 주소를 엽니다.

계정이 ymkim0702이고 저장소 이름이 icetlab이라면 예상 주소:
https://ymkim0702.github.io/icetlab/
이 주소는 배포를 완료해야 사용할 수 있습니다. 저장소 이름이 달라지면 주소도 달라집니다.

## 이후 수정

- 문구·논문·연구원·뉴스: index.html 수정
- 이미지: assets 안의 해당 파일 교체 (같은 파일명을 유지하면 HTML 수정 불필요)
- 변경 내용을 main에 Commit하면 Pages가 다시 배포합니다.
- Google Fonts는 인터넷으로 불러오며, 이미지들은 이 저장소에 포함되어 있습니다.
- ChatGPT Sites와 GitHub는 자동 동기화되지 않습니다. 이전 후 GitHub를 기준으로 수정하세요.
- 이번 패키지는 업로드 준비본이며, GitHub 저장소에는 아직 업로드하지 않았습니다.
